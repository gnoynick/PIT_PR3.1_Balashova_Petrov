# PIT_PR3_Balashova_Petrov
Приложение 1 (Фибоначчи): точки останова, пошаговое выполнение ("Шаг с заходом" и "Шаг с обходом"), панель локальных переменных.
Приложение 2 (Галактика): точки останова, пошаговое выполнение кода, просмотр значений переменных в реальном времени, исправление кода во время отладки, горячая перезагрузка.
Приложение 3 (Буквы): установка точки останова, пошаговое выполнение кода, навигация по коду, отладка с помощью подсказок по данным, использование окон "Авто" и "Локальные", наблюдение за переменными с помощью окна "Watch", проверка стека вызовов, перезапуск приложения.
